# Portafolio Profesional - Colegio El Belloto
## Descripción
Portafolio web académico personal desarrollado para la asignatura de Pensamiento Computacional y Programación de 4.º Medio[cite: 12]. Presenta información personal, una sección de proyectos técnicos y un formulario de contacto.

## Enlace al sitio publicado
Puedes ver el sitio en funcionamiento en el siguiente enlace de GitHub Pages:
https://tu-usuario.github.io/Evaluaci-n-Formativa-N-2-main/

## Funcionalidades con JavaScript
* **Modo Oscuro / Modo Claro:** Permite alternar la interfaz visual de la página entre un tema claro y un tema oscuro dinámicamente mediante un botón en la barra de navegación[cite: 16, 17].
